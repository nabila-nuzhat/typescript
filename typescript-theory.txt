- @types/node /react
  - if node/react used with typescript.

  - provides type definitions for Node.js's built-in APIs — things like fs, path, http, process, Buffer, etc. TypeScript doesn't know the shapes of these APIs on its own, since Node.js itself is written in plain JavaScript with no types built in.

  Why you need it

  Without @types/node, TypeScript treats Node's globals and built-in modules as unknown or any, and you'll get errors like:

  Cannot find module 'fs' or its corresponding type declarations.
  Cannot find name 'process'.
